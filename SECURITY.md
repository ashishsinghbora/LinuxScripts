## Reporting a Vulnerability

If you discover a security vulnerability within any script or configuration in this repository:

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Please report findings responsibly via GitHub Security Advisories on the repository or directly to the repository maintainer.
3. Include details of the vulnerability, affected scripts, and a proof of concept or reproduction steps.

All security issues will be promptly investigated and addressed.
